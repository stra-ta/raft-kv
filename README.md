# raft-kv

[![CI](https://github.com/stra-ta/raft-kv/actions/workflows/ci.yml/badge.svg)](https://github.com/stra-ta/raft-kv/actions/workflows/ci.yml)

A from-scratch Raft implementation with a deterministic simulator and real Rust processes over raw TCP.

## Measured simulator behavior

| Metric | Value |
| --- | ---: |
| First leader elected | 176 ms simulated |
| Failover after leader kill | 244 ms simulated |
| Write visible on all five nodes | 52 ms simulated |
| Fault tolerance | 2 failed nodes |
| Process-level TCP tests | 3 |

These are deterministic simulator timings generated by `raft-demo`, not wall-clock distributed-system performance.

![A five-node cluster dashboard](docs/cluster-dashboard.svg)

The simulator controls time, messages, partitions, duplication, reordering, stops, and restarts.
The process runner adds framed TCP, atomic Raft persistence, and an LSM-backed state machine.

## Current boundary

- Three to five nodes
- Majority-committed writes and current-term read barriers
- Durable term, vote, log, snapshot boundary, and state-machine recovery
- Deterministic histories with linearizability checks
- No membership changes, TLS, authentication, or production claim

## Verification

Functional CI and performance evidence are separate. See [GUIDE.md](GUIDE.md) and `LAB_RULES.md` / `EVIDENCE.md` in `stra-ta/.github` for manifest provenance and the one-command suite (`./scripts/verify.sh` / `./scripts/confidence.sh` or `tools/verify.sh`).

## Limitations

CI is functional only. Performance evidence requires a committed manifest with machine metadata (commit, compiler, kernel, CPU, arch, build type, seed, argv) and a link from the claim to that artifact. See `stra-ta/.github` for lab-wide caveats.
